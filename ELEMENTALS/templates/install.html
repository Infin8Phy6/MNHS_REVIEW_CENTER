Play without internet

ELEMENTALS is a small Python program with its own database file. Nothing is sent to the internet: the tiles, the clues and every score stay inside this folder.

Download the app (ELEMENTALS.zip)

1 · Put the folder on the computer

  • Copy the ELEMENTALS folder from this machine, or download the zip above and unzip it.
  • The folder needs app.py, periodic_data.py, clue_data.py, templates\, static\ and elements.db.

2 · Install Python once

  • From python.org/downloads install Python 3.9 or newer. On Windows tick Add python to PATH during setup.
  • Then, one time, in a terminal inside the folder: pip install -r requirements.txt

3 · Open the app

  • Windows: double-click run.bat.
  • Mac: double-click run.command.
  • Any computer: python app.py — the browser opens by itself.
  • Classroom mode: python app.py --lan prints an address such as http://192.168.1.9:8000 that other computers on the same wifi can open. No internet is needed for that either.

4 · Add it to the desktop like a real app

  • Open the app in Chrome or Edge and press the Install icon at the right end of the address bar (or the menu → Apps → Install this site as an app).
  • ELEMENTALS then gets its own window, taskbar icon and Start-menu entry. The pages and the element tiles are cached, so they still open even if the server window was closed — starting run.bat again brings the game itself back.

What is in the database

  • elements — {{ total_elements }} tiles: atomic number, chemical symbol, element name, atomic mass, group and period, electron configuration, oxidation states, state of matter and the metal / nonmetal / metalloid class that drives the tile colour.
  • clues — three classroom clues for {{ clued_elements }} of those elements; only elements with clues are drawn into a game.
  • games and answers — every attempt with the level it was played on (with choices or hard, where the symbol is typed and capitalisation counts), so the teacher can reopen saved scores and see who played which set of ten.

The app picks {{ rows }} elements at a time and prints them across the nine columns: Element, Symbol, Mass Number, Proton Number, Neutron Number, Electron Count, Valence Electron, Period and Group. {{ blanks }} cells in every row are emptied — {{ rows }} × {{ blanks }} = {{ max_points }} points, one point for each cell you fill in correctly.

The clues are the laws themselves

  • Proton Number = Electron Count — a neutral atom holds one electron for every proton.
  • Mass Number = Proton Number + Neutron Number — so any two of the three give the third.
  • Period = the shell the valence electrons sit in, and the row of the table.
  • Group = the valence count for the main groups: 1 gives 1, 2 gives 2, and 13–18 give 3–8. Helium, in group 18 of period 1, holds 2.
  • One element per Period and Group — group 2 in period 3 can only be one element.

{{ count }} elements may be dealt: the main groups ({{ groups }}) of periods {{ periods }}. Nothing outside them is asked for, and no cell is emptied unless the clues left in its own row still pin that row to a single element.
